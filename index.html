ℹ Protocol Info

Active: GMVEMSC Protocol (Default)

EMS Narrator ships with the GMVEMSC (Greater Miami Valley EMS Council) protocol built in. You can add or remove individual items in any section using the ✏ Edit button on that section. Need a different regional protocol loaded? Email supersonicandchill@gmail.com and we'll set it up.

🔑 Claude API Key

EMS Narrator uses your own Anthropic API key to generate narratives with Claude. Your key is stored only on this device and is sent directly to Anthropic — never to us. No key? You can still build offline narratives without AI — see below.

Don't have a key? Get one free at console.anthropic.com — takes about 2 minutes. Claude API usage is billed by Anthropic directly based on your usage, typically fractions of a cent per narrative.
